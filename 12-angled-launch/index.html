How to use this simulation

  1. Set the launch speed u, the angle θ above the horizontal and the launch height h (0 = from the ground).
  2. Press ▶ Launch. The strobe shows the ball every 0.1 s; the dashed lines mark the maximum height H and the range R.
  3. With Keep paths on, earlier launches stay on the screen (faint) so you can compare angles. ↺ Clear removes them.
  4. Press ● Record. The Data tab plots R against θ for the current speed and height, with the theory curve if you want it.
  5. Work through the Tasks tab. Write explanations on your worksheet.

The physics

  • Resolve the launch velocity: ux = u cos θ, uy = u sin θ.
  • Horizontal: ax = 0, so x = uxt. Vertical: ay = −g, so y = h + uyt − ½gt², vy = uy − gt.
  • At the top vy = 0: ttop = uy/g, H = h + uy²/(2g). The ball still moves sideways at ux.
  • From the ground (h = 0): T = 2uy/g and R = uxT = u² sin 2θ / g — largest at 45°, and equal for complementary angles (e.g. 30° and 60°).

Model: no air resistance (see Simulation 15); g = 9.81 (Earth), 1.62 (Moon), 3.71 (Mars) m s⁻². The ball is drawn bigger than to scale; x and y use the same scale, so the shape of the path is true.
